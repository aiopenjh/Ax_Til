## 2. 개념과 용어 정리
### HTML의 개념과 텍스트 태그
```bash
HTML은 웹페이지의 뼈대를 구성하는 건축설계도
 - 마크업언어(Markup Language): 태그(Tag)를 사용해 문서 구조화
 - 웹표준(Web Standard): 웹페이지를 구성하는 요소들의 표준(크롬, 사파리, 엣지 등)
 - 태그(Tag): 상품정보 택처럼 웹페이지의 특정 글자나 그림이 어떤 역할을 가지는 지 알려주는 이름표
 - HTML주석 <!-- --> : 코드에 설명을 추가, 웹브라우저에 표시되지 않음
 - 제목 태그(<h1>~<h6>)로 중요도 표현 : 제목태그 <h1>이 가장 대제목이며 숫자가 커질수록 중요도가 낮아짐
 ```
  - HTML 문서 기본 구조
    ```bash
    <!DOCTYPE html>              -- html 문서임을 선언
    <html lang="ko">             -- html 문서의 시작과 끝, lang="ko"는 한국어로 작성됨을 의미
    <head>
        <meta charset="UTF-8">    -- 웹페이지의 정보를 담은 머리글, charset="UTF-8"은 한글을 표시하 기 위한 설정
        <title>나의 첫 웹 문서</title> -- 웹페이지의 제목, 브라우저의 탭에 표시됨
    </head>                       -- head 태그의 끝
    <body>                          -- 웹페이지에 보이는 본문
    화면에 글자가 나타납니다.       -- 웹페이지에 표시될 내용
    </body>                         -- body 태그의 끝
    </html>                         -- html 문서의 끝
    ```
```bash
 - 화면을 채우는 두가지 방식 : 블록(Block) vs 인라인(Inline)
  - 블록요소 : 면적(상자)의 개념을 가짐. 새로운 정보의 묶음이나 문단을 시작할 때 주로 사용
  - 인사인요소 : 흐름(선)의 개념을 가짐. 문장 내부의 특정 단어나 일부분만 꾸며줄 때 주로 사용
   * 일반적으로 블록 요소 내부에는 블록요소와 인라인요소를 모두 넣을수있지만, 인라인 요소 내부에는 블록 요소를 넣을수가 없다. ex) <p><sapn>Text</span></p> (O) //  <p><sapn><p>Test</p></sapn></p>(X)
```

### 하이퍼링크, 멀티미이더 및 폼 태그
```bash
하이퍼링크 태크 와 경로지정 , 멀티미디어 사입 태그 , 사용자 입력서식 폼태그
 - <a></a> : 하이퍼링크 태그
   - href="" : 이동할 페이지의 주소를 담는 속성
   - target="" : 링크를 클릭했을때 이동할 방식
 - 하이퍼링크 절대경로 : 인터넷상의 고유한 전체 주소
 - 하이퍼링크 상대경로 : 현재 페이지를 기준으로 경로를 지정
 - 미디어태그 : 쌍으로이루어진 <video> , <audio>와 단독으로 사용되는 <img>로 구분됨
 - 사용자 입력 서식, 폼 태그 : <form>, <input> 등 사용자 입력을 받는 상자
```

 
### ⭐️ 필수 (실무 핵심 90%) - 반드시 기억
```bash
| 용어/명령어 | 뜻 | 기억할 점 / 주의점 1 |
|---|---|---|
| <h1~h6> | 제목 태그 | <h1>가 가장 중요한것을 숫자가 커질수록 중요도가 낮아지며 크기가 작아짐 |
| 블록(Block)요소 | 항상 새로운 줄에서 시작하며, 가로로 최대한 늘어남. 태그를 사용하면 자동 줄바꿈 | <h1~h6>, <p>, <div>, <ul>, <ol>, <li> 등 |
| 인라인(Inline)요소 | 줄의 흐름에 따라 배치되며, 콘텐츠의 너비만큼만 공간을 차지함. 줄바꿈 안됨 | <a>, <span>, <img>, <strong>, <em> 등 |
```
```bash
| 용어/명령어 | 뜻 | 기억할 점 / 주의점 2 |
|---|---|---|
| _self(기본값) | 현재 창에서 링크를 연다 | 별도로 적지않으면 이대로 작동 |
| _blank | 새창에서 링크를 연다 | _blank로 지정된 탭이 이미 열려있다면 해당탭에서 열린다 |
| _top | 현재 창의 프레임 구조에서 가장 최상단에서 링크를 연다 | frames 구조일때 유용 |
| _parent | 현재 창의 부모 프레임에서 링크를 연다 | frames 구조일때 유용 |
```
```bash
| 용어/명령어 | 뜻 | 기억할 점 / 주의점 3 |
|---|---|---|
| <img> | 이미지 삽입 | 이미지를 화면에 표시. 닫는 태그 없음 |
| src | 파일 경로 | 이미지·영상·음성 파일이 어디 있는지 지정 |
| alt | 대체 텍스트 | 이미지가 안 뜰 때 대신 표시할 설명. <img>에서 중요 |
| <video> | 동영상 삽입 | 웹페이지에 동영상 재생 |
| <audio> | 오디오 삽입 | 웹페이지에 소리 재생 |
| controls | 재생 버튼 표시 | 재생·정지·볼륨 등의 조작 버튼을 보여줌 |
```
```bash
| 용어/명령어 | 뜻 | 기억할 점 / 주의점 4 |
|---|---|---|
| <form> | 입력 데이터 묶음 | 사용자가 입력한 데이터를 묶어서 서버로 보낼 때 사용 |
| action | 보낼 주소 | 입력 데이터를 어느 서버 주소(URL)로 보낼지 지정 |
| method | 전송 방식 | 데이터를 어떤 방식으로 서버에 요청할지 지정 |
| GET | 조회(Read) | 데이터를 가져오거나 조회할 때 주로 사용. 데이터가 URL에 붙을 수 있음 |
| POST | 생성/변경(Write) | 데이터를 보내서 생성·수정 등 서버 상태를 바꿀 때 주로 사용 |
```

### 💡 참고 (검색용) - 이해만 하고 넘어가기
```bash
 - <p></p> : 하나의 독립된 문단(Paragraph)을 만듬, 태그가 끝나면 자동 줄바꿈과 여백이 생김
 - <br> : 문단 안에서 강제로 줄바꿈(Break)을 할때 사용, 끝 태그가 없는 단독태그
 - <span></span> : 줄바꿈없이 문장안에서 특정 글자만 따로 묶어서 스타일을 지정할때 사용
 - <strong></strong> : 텍스트에 중요도를 줌, 시각적으로 굵은 글씨로 표시
 - <em></em> : 텍스트에 강조 효과를 줌, 시각적으로 기울인 글씨로 표시
 - <mark></mark> : 형광펜으로 칠한 듯 강조
 - <u></u> : 밑줄을 쳐서 강조
 - <hr> : 화면을 가로지르는 구분선
 - <div></div> : 화면의 특정 영역을 묶는 상자
 
 - width / height : 크기 지정 : 너비 / 높이 지정. 숫자만 쓰면 기본적으로 px
 - autoplay : 자동 재생 : 페이지가 열리면 자동 재생. 브라우저가 제한할 수 있음
 - muted : 음소거 : 소리를 끈 상태로 시작
 - loop : 반복 재생 : 끝나면 처음부터 다시 재생
 - poster : 영상 썸네일 : <video> 전용. 영상 재생 전 보여줄 이미지
 ```
