## 2. 개념과 용어 정리

### 📌 핵심 포인트
1. 키-값(key-value)구조 : 딕셔너리는 데이터를 저장할때 고유한 식별자인 key와 실제 저장 할 값 Value를 한쌍으로 관리하는 구조. 중괄호({})
2. 집합의 정의와 순서없는(Unordered) 특성 : 집합 내의 모든 요소는 무조건 고유해야됨, 동일한 데이터를 여러번 추가해도 set은 자동으로 고유한 요소만 기억
3. 자료구조간의 상호 변환과 데이터 정제 : 중복 제거: list / tuple을 set으로 변환해 중복을 없앤 후 다시 원래 자료형으로 재변환 // 불변성 우회: 수정 불가능한 튜플도 list로 변환해 값을 수정한 뒤 다시 tuple로 새로 생성하여 가공 가능

---

### ⭐️ 필수 (실무 핵심 90%) - 반드시 기억

| 용어/명령어 | 뜻 | 기억할 점 / 주의점 |
|---|---|---|
| 리스트(List) | 순서가 있는 값들의 모음. 여러 자료형을 담을 수 있음 | 대괄호[] 사용. 인덱싱, 슬라이싱, append(), pop() 등 다양한 함수로 데이터 조작 가능 |
| 튜플(Tuple) | 순서가 있는 값들의 모음. 리스트와 유사하지만 변경 불가능 | 소괄호() 사용. 데이터 보호나 함수 인자로 많이 쓰임 |
| 딕셔너리(Dictionary) | 키(Key)-값(Value) 쌍으로 이루어진 모음. 순서가 없음 | 중괄호{} 사용. 키로 빠르게 값을 조회할 때 사용 |
| 집합(Set) | 중복을 허용하지 않고 순서가 없는 값들의 모음 | 중괄호{} 또는 set() 사용. 중복 자동 제거, 인덱싱 불가, 빈 세트는 set()으로 생성 |
| 인덱싱(Indexing) | 리스트, 튜플, 문자열 등에서 특정 위치의 값을 가져오는 기능 | 대괄호[]에 숫자 인덱스 사용. 파이썬은 0부터 시작 역방향은 -1 부터 시작 |
| 슬라이싱(Slicing) | 리스트, 튜플, 문자열 등에서 특정 범위의 값을 잘라내는 기능 | 대괄호[시작:끝:간격] 사용. [이상:미만] 규칙으로 '끝' 인덱스 직전까지만 추출됨에 주의 |
| 길이측정 len() | 시퀀스 자료형의 길이를 측정 | len(list) \| len(tuple) \| len(dict) \| len(string) |

| 집합 연산 | 두 그룹 간의 교집합, 합집합, 차집합 연산 | 교집합(`&`), 합집합(`\|`), 차집합(`-`)으로 공통 요소나 차이 빠르게 계산 |
| 딕셔너리 Key 조건 | 키(Key)는 반드시 변하지 않는 고유값이어야 함 | 문자열, 숫자, 튜플은 가능 / 리스트는 변경 가능하므로 불가능 |

## 3. 예제 및 실습

### 실습 내용
```python
# 1. 패킹과 언패킹
packed_data = 1, 2, 3 # 자동으로 튜플로 패킹됨 (1, 2, 3)
a, b, c = packed_data # 튜플 언패킹

# 2. * 연산자를 활용한 가변 언패킹
first, *others = [10, 20, 30, 40, 50]
print(first)  # 출력: 10
print(others) # 출력: [20, 30, 40, 50] (나머지 요소들을 리스트로 받음!)

# 3. 집합 연산 예시 (교집합, 합집합, 차집합)
team_a = {"철수", "영희", "민수"}
team_b = {"영희", "민수", "동현"}
print(team_a & team_b)  # 교집합: {'영희', '민수'}
print(team_a | team_b)  # 합집합: {'철수', '영희', '민수', '동현'}
print(team_a - team_b)  # 차집합: {'철수'}
```
```python
set_a = {1, 2, 3}
```

## 4. 실수 및 트러블슈팅

### 발생한 문제 요약
- 상황: "튜플은 불변(수정 불가)이라고 했는데, list()로 변환해서 값을 고치고 다시 tuple()로 바꾸면 결국 수정되는 것 아닌가?"라는 의문 발생
- 원인: 원본 튜플의 데이터를 직접 수정하는 것(In-place modification)과, 알맹이를 복사해 완전히 새로운 바구니(객체)를 새로 찍어내는 것을 혼동함
- 해결: 원본 튜플 자체는 절대로 변하지 않고 그대로 유지되며, list 변환 후 재변환 과정은 '새로운 튜플'을 새로 생성하는 우회 기법임을 확인

## 5. 오늘의 핵심
- 파이썬의 4대 핵심 자료구조(리스트, 튜플, 딕셔너리, 집합)의 특징과 사용법을 명확하게 구분하는 연습이 필요

- 한 문장 요약: 데이터의 특성에 맞춰 올바른 자료구조(리스트·튜플·딕셔너리·셋)를 선택하고, 변환을 통해 자유자재로 정제할 수 있는 기초를 확인했다.
