## 2. 개념과 용어 정리
### HTML의 개념과 텍스트 태그
```html
HTML은 웹페이지의 뼈대를 구성하는 건축설계도
 - 마크업언어(Markup Language): 태그(Tag)를 사용해 문서 구조화
 - 웹표준(Web Standard): 웹페이지를 구성하는 요소들의 표준(크롬, 사파리, 엣지 등)
 - 태그(Tag): 상품정보 택처럼 웹페이지의 특정 글자나 그림이 어떤 역할을 가지는 지 알려주는 이름표
 - HTML주석 <!-- --> : 코드에 설명을 추가, 웹브라우저에 표시되지 않음
 - 제목 태그(<h1>~<h6>)로 중요도 표현 : 제목태그 <h1>이 가장 대제목이며 숫자가 커질수록 중요도가 낮아짐
 ```
  - HTML 문서 기본 구조
    ```html
    <!DOCTYPE html>              -- html 문서임을 선언
    <html lang="ko">             -- html 문서의 시작과 끝, lang="ko"는 한국어로 작성됨을 의미
    <head>
        <meta charset="UTF-8">    -- 웹페이지의 정보를 담은 머리글, charset="UTF-8"은 한글을 표시하 기 위한 설정
        <title>나의 첫 웹 문서</title> -- 웹페이지의 제목, 브라우저의 탭에 표시됨
    </head>                       -- head 태그의 끝
    <body>                          -- 웹페이지에 보이는 본문
    화면에 글자가 나타납니다.       -- 웹페이지에 표시될 내용
    </body>                         -- body 태그의 끝
    </html>                         -- html 문서의 끝
    ```
```html
 - 화면을 채우는 두가지 방식 : 블록(Block) vs 인라인(Inline)
  - 블록요소 : 면적(상자)의 개념을 가짐. 새로운 정보의 묶음이나 문단을 시작할 때 주로 사용
  - 인사인요소 : 흐름(선)의 개념을 가짐. 문장 내부의 특정 단어나 일부분만 꾸며줄 때 주로 사용
   * 일반적으로 블록 요소 내부에는 블록요소와 인라인요소를 모두 넣을수있지만, 인라인 요소 내부에는 블록 요소를 넣을수가 없다. ex) <p><sapn>Text</span></p> (O) //  <p><sapn><p>Test</p></sapn></p>(X)
```

### 하이퍼링크, 멀티미이더 및 폼 태그
```html
하이퍼링크 태크 와 경로지정 , 멀티미디어 사입 태그 , 사용자 입력서식 폼태그
 - <a></a> : 하이퍼링크 태그
   - href="" : 이동할 페이지의 주소를 담는 속성
   - target="" : 링크를 클릭했을때 이동할 방식
 - 하이퍼링크 절대경로 : 인터넷상의 고유한 전체 주소
 - 하이퍼링크 상대경로 : 현재 페이지를 기준으로 경로를 지정
 - 미디어태그 : 쌍으로이루어진 <video> , <audio>와 단독으로 사용되는 <img>로 구분됨
 - 사용자 입력 서식, 폼 태그 : <form>, <input> 등 사용자 입력을 받는 상자
```

### HTML5 시멘틱 태그의 구조화
HTML5 시멘틱 태그 : 태그자체에 의미'Semantic'을 담아, 웹문서의 구조를 정의하는 태그

### ⭐️ 필수 (실무 핵심 90%) - 반드시 기억
```html
| 용어/명령어 | 뜻 | 기억할 점 / 주의점 1 |
|---|---|---|
| <h1~h6> | 제목 태그 | <h1>가 가장 중요한것을 숫자가 커질수록 중요도가 낮아지며 크기가 작아짐 |
```

### 💡 참고 (검색용) - 이해만 하고 넘어가기
```html
 - <p></p> : 하나의 독립된 문단(Paragraph)을 만듬, 태그가 끝나면 자동 줄바꿈과 여백이 생김
 - <br> : 문단 안에서 강제로 줄바꿈(Break)을 할때 사용, 끝 태그가 없는 단독태그

 - <div></div> : 화면의 특정 영역을 묶는 상자
 
 - width / height : 크기 지정 : 너비 / 높이 지정. 숫자만 쓰면 기본적으로 px

 - loop : 반복 재생 : 끝나면 처음부터 다시 재생

 - type="range" : 슬라이더
 - type="time" : 시간 선택
 - type="datetime-local" : 날짜 + 시간 선택
 - type="color" : 색상 선택
 ```

## 3. 예제 및 실습

### 실습 내용

무엇을 만들거나 연습했는지 적는다.

```html
실습에 사용한 명령어나 코드
<a href="./practice_html/index.html" target="_self">첫 예제 실습 바로가기</a>
로 테스트완료
```

### 실행 결과
- 정상적으로 된 부분: index.html에서 실습코드들을 하나하나 쳐보면서 정신없었지만, 정리가 됬고 실행이 되는걸 눈으로 봤다, 물론 다 기억을 하기엔 쉽지않을 거같지만 어떤 기능이 어떻게 작용하는지 감은 잡을 수 있을 것 같다.
- 새롭게 확인한 부분: 폼태그의 종류가 생각보다 많고, 각각의 역할이 구체적이라는 점, 또한 semantic tag를 적절히 활용하는 것이 웹사이트 구조를 잘 잡는 데 중요할 것 같다.
