## 2. 개념과 용어 정리 및 예시

### 2.1 함수의 정의와 구성 요소
> 함수는 특정 연산을 수행하기 위해 설계된 독립적인 코드 블록입니다.

#### 함수의 구조
```js
// square 함수 정의
function square(x) {
    return x * x; // 전달받은 매개변수 x를 제곱하여 결과를 반환합니다.
}

// square 함수 호출
square(5); // 인수 5를 전달하며 함수를 실행합니다.
```
- 함수 이름 (Function Name): `square`가 이에 해당하며, 정의된 함수를 식별하고 호출할 때 사용하는 이름입니다.
- 매개변수 (Parameter): `x`가 이에 해당하며, 함수 외부에서 내부로 데이터를 전달받기 위해 함수 정의 시 선언해 두는 '임시' 변수입니다.
- 함수 바디 (Function Body): `{ return x * x; }` 영역으로, 중괄호 내부에서 실제로 수행할 연산 로직을 작성하는 곳입니다.
- 반환값 (Return Value): `return` 키워드 뒤에 오는 `x * x` 연산 결과로, 함수 실행을 끝마치고 호출한 곳으로 돌려주는 결과 데이터값입니다.
- 인수 (Argument): 호출 시 대입한 `5`가 이에 해당하며, 함수를 실제로 호출하여 실행할 때 매개변수 자리에 넣어주는 실제 데이터값입니다.

### 2.2 함수 호출과 제어 흐름

#### 함수 호출 문법
함수를 실행하려면 함수 이름 뒤에 호출 연산자인 `()`를 붙이고, 문장 끝에는 자바스크립트 명령문의 종료를 알리는 세미콜론(`;`)을 작성합니다.
- 호출 연산자 `()`: 함수 이름 뒤에 소괄호를 붙여야 실제 함수 내부에 작성된 코드가 실행되며, 괄호가 없으면 함수를 실행하는 것이 아니라 함수 객체 자체를 가리키게 됩니다.
- 세미콜론 `;`: 자바스크립트에서 하나의 명령문(Statement)이 완료되었음을 명시하는 기호입니다.

#### 함수 호출 시의 제어 흐름
함수가 호출되면 프로그램의 실행 제어권이 호출부에서 함수 정의부로 이동하며, 반환값을 넘겨주어 다시 호출부로 복귀합니다.
```js
// 호출 연산자와 제어 흐름 확인
console.log("1. 함수 호출 전");

// 함수가 호출되면 실행 흐름이 getGreeting 정의부 내부로 이동합니다.
const message = getGreeting("이용교"); 

console.log("4. 함수 호출 완료 및 결과 출력:", message);

function getGreeting(name) {
    console.log("2. 함수 실행 시작");
    const result = `안녕하세요, ${name}님.`;
    console.log("3. 함수 실행 종료 및 반환");
    return result; // 호출부로 결과값을 반환하며 복귀합니다.
}
```

#### 인수의 유연성과 가변 매개변수
자바스크립트는 매개변수의 수와 인수의 수가 정확히 일치하지 않아도 에러 없이 유연하게 동작합니다. 또한 매개변수 기본값을 설정하거나 들어오는 인수의 개수가 정해지지 않은 가변적인 상황을 처리할 수 있습니다.
- 매개변수 기본값 (Default Parameter): 호출 시 인수를 생략하여 아무런 값도 대입되지 않을 때(`undefined`), 미리 지정한 기본값으로 채우는 기능입니다.
- arguments 객체: 함수 호출 시 전달된 모든 인수 정보가 자동으로 담기는 유사 배열 객체입니다. (과거 방식)
- 나머지 매개변수 (Rest Parameter, 가변 매개변수): 매개변수 이름 앞에 마침표 3개(`...`)를 붙여 사용하는 현대적인 방식으로, 들어오는 가변적인 개수의 인수들을 진짜 배열로 묶어 처리합니다.

### 2.3 함수 정의 방식: 선언문 vs 표현식
자바스크립트에서 함수를 선언하는 방식은 선언문과 표현식으로 구분되며, 각 방식에 따라 호이스팅 여부가 다릅니다.

#### 1) 함수 선언문 방식
`function` 키워드 뒤에 함수명을 명시하여 단독 문장으로 정의하는 방식입니다.
- 호이스팅 여부: 자바스크립트 엔진이 스크립트를 실행하기 전 평가 단계에서 함수 선언을 메모리에 먼저 등록하므로, 실제 선언 코드보다 윗줄에서 호출하더라도 정상 동작합니다.
```js
// 함수 선언문 사용 및 호이스팅 확인
// 아래에 정의된 getArea 함수를 선언부 이전에 호출합니다.
console.log("선언문 호출 결과:", getArea(5, 10)); // 출력: 50

function getArea(width, height) {
    return width * height; 
}
```

#### 2) 함수 리터럴 (표현식) 방식
이름이 없는 익명 함수를 생성한 후 변수에 할당하여 사용하는 방식입니다.
- 호이스팅 여부: 함수를 담은 변수 선언 자체는 인지되나 실제 함수 할당은 런타임(실행 단계)에 순차적으로 발생하므로, 할당 코드 이전에 호출하면 참조 에러(`ReferenceError`)가 발생합니다.
```js
// 함수 표현식 사용 및 호출 타이밍 확인
try {
    // 할당이 이루어지기 전에 호출을 시도합니다.
    console.log(getVolume(5, 10, 2)); 
} catch (error) {
    console.log("할당 전 호출 에러:", error.message);
    // 출력: Cannot access 'getVolume' before initialization
}

// 익명 함수를 변수 getVolume에 할당합니다.
const getVolume = function(width, height, depth) {
    return width * height * depth; 
};

// 할당이 완료된 이후 호출하면 정상 구동됩니다.
console.log("할당 후 정상 호출 결과:", getVolume(5, 10, 2)); // 출력: 100
```

### 2.4 값으로서의 함수 (일급 객체)와 콜백
자바스크립트에서 함수는 특수 제어 명령이 아닙니다. 숫자나 문자열처럼 메모리에 기록되고 자유롭게 전달될 수 있는 일반 데이터와 동등한 값으로 취급됩니다. 이를 프로그래밍 언어 디자인 측면에서 일급 객체(First-class Object) 또는 일급 시민(First-class Citizen)이라고 부릅니다.

#### 용어의 유래: 차별 없는 '동등한 권리'
- 사회학에서의 유래 (일급 시민 vs 이등 시민): 프로그래밍 언어 디자인에서 함수가 다른 일반 데이터와 동등한 권리를 갖는다는 점을 강조하기 위해 도입된 용어입니다.
- 자바스크립트의 4대 일급 객체: 숫자, 문자열, 객체, 함수

#### 일급 객체로서의 3대 속성
- 변수 할당 (Assignment): 함수를 변수에 대입할 수 있으며, 변수명을 통해 원래 함수를 언제든 호출할 수 있습니다.
- 매개변수 전달 (Argument Passing): 다른 함수의 인수로 함수 자체를 넘겨줄 수 있습니다. 이때 인수로 전달되어 다른 함수 내부에서 호출되는 함수를 '콜백 함수 (Callback Function)'라고 합니다.
- 반환값 활용 (Return Value): 함수가 다른 함수의 실행 결과물로서 반환(Return)될 수 있습니다.

### 2.5 화살표 함수 (Arrow Function)
`function` 키워드 대신 `=>` 기호를 사용하여 함수를 간결하게 표현하는 단축 선언문으로, 콜백 함수의 작성을 단순화할 때 주로 사용합니다.

#### 정의 방법 및 스코프 생략 규칙
화살표 함수는 구현되는 연산 구조에 따라 문법적 단축 규칙을 제공합니다.
- 소괄호 `()` 생략: 전달받을 매개변수가 오직 1개인 경우에만 매개변수를 감싸는 소괄호 `()`를 생략할 수 있습니다.
- 중괄호 `{}` 및 `return` 생략: 함수 내부가 단 한 줄의 return 문으로 이루어져 있을 경우, 중괄호와 return 키워드를 모두 생략하여 한 문장으로 정의가 가능합니다.
```js
// 화살표 함수의 생략 규칙 적용 예시

// 단축을 적용하지 않은 표준 화살표 함수 형태
const add = (a, b) => {
    return a + b;
};

// 매개변수가 1개이므로 매개변수 소괄호() 생략
const square2 = x => {
    return x * x;
};

// 한 줄의 리턴문이므로 중괄호{}와 return 키워드를 동시에 생략
const multiply = (a, b) => a * b;

// 매개변수 1개 및 리턴문 1줄 조건을 동시에 충족하여 축약한 형태
const double = x => x * 2;

// 매개변수가 아예 없을 때는 소괄호()를 생략할 수 없습니다.
const sayHello = () => "안녕하세요";

console.log("실행 데이터:", add(2, 3), square2(4), multiply(3, 5), double(6), sayHello());
// 출력: 실행 데이터: 5 16 15 12 안녕하세요
```

#### 화살표 함수의 제한사항
간결한 구조를 유지하기 위해 화살표 함수는 다음의 기능들을 지원하지 않습니다.
- 생성자 함수 사용 불가: 자체적인 `prototype` 객체를 생성하지 않으므로 `new` 연산자를 사용해 인스턴스 객체를 생성할 수 없습니다.
- arguments 객체 미지원: 함수 내부로 유입된 인수 목록 정보를 가지고 있는 `arguments` 유사 배열 객체가 존재하지 않습니다. 가변 인수를 받으려면 나머지 매개변수(`...args`) 방식을 사용해야 합니다.
- yield 사용 불가: 제너레이터(Generator) 함수로 구성할 수 없습니다.
```js
const showArgs = (...args) => {
    // arguments 변수 대신 가변 매개변수인 args 배열을 정상 조작합니다.
    console.log(args); 
};
showArgs(1, 2, 3); // 출력: [1, 2, 3]
```

#### 일반 함수 vs 화살표 함수의 this 바인딩 비교
`this`는 함수가 호출될 때, 그 함수를 호출한 주체(객체)를 가리키는 자바스크립트의 특별한 키워드입니다.
- 일반 함수: 호출되는 방식에 따라 `this`가 동적으로 바인딩됩니다. (객체의 메서드로 호출 시 호출 주체 객체를 지칭)
- 화살표 함수: 스스로 `this`를 결정하지 않습니다. 함수가 작성된 주변 환경(상위 스코프)의 `this`를 그대로 가져와 변하지 않는 값으로 사용합니다.
```js
// 일반 함수와 화살표 함수의 this 바인딩 거동 차이 비교
const user = {
    name: "이용교",
    // 일반 함수 기반 메서드
    regularGreet: function() {
        console.log("일반 메서드 this.name:", this.name); // 자신을 소유 및 호출한 user 객체 참조
        
        const innerFunc = function() {
            console.log("중첩 일반 함수 this:", this); // 단독 호출된 일반 함수의 this는 기본적으로 전역(Window/Global)을 지칭
        };
        innerFunc();
    },
    // 화살표 함수 기반 메서드
    arrowGreet: function() {
        const innerArrow = () => {
            console.log("중첩 화살표 함수 this.name:", this.name); 
            // 화살표 함수는 선언 시점의 상위 영역(arrowGreet)의 this인 user 객체를 상속받습니다.
        };
        innerArrow();
    }
};

user.regularGreet();
user.arrowGreet();
```

### 2.6 자바스크립트 실행 평가 과정과 클로저 (Closure)
자바스크립트 엔진은 코드를 실행하기 전 준비하는 평가 단계와 실제로 실행하는 실행 단계를 명확히 구분하여 연산을 수행합니다.

#### 엔진의 2단계 제어 프로세스
1. 1단계: 평가 단계 (Creation/Evaluation Phase)
   - 자바스크립트 코드를 즉시 한 줄씩 실행하지 않고 전체 구조를 먼저 훑어봅니다.
   - 변수 선언과 함수 식별자 정보를 메모리 공간에 미리 매핑(등록)하여 코드 하단에 있는 함수를 위에서 미리 참조할 수 있는 호이스팅 현상이 발생합니다.
2. 2단계: 실행 단계 (Execution Phase)
   - 평가 과정이 완료되면 비로소 첫 라인부터 연산을 순차 실행합니다.
   - 변수에 실제 데이터 값을 주입하고 필요한 함수를 정상 호출합니다.

#### 데이터 정렬과 호출 스택 (Call Stack)의 동작 방식
프로그램 내에서 여러 함수가 연속적으로 호출될 때, 실행 중인 순서와 제어 복귀 경로를 통제하는 메모리 영역을 호출 스택(Call Stack)이라 합니다. 호출 스택을 이해하기 위해서는 데이터 처리 규칙인 FIFO와 LIFO를 알아야 합니다.
- 선입선출 (FIFO, First In, First Out): 가장 먼저 들어간 데이터가 가장 먼저 나오는 방식
- 후입선출 (LIFO, Last In, First Out): 가장 마지막에 들어간 데이터가 가장 먼저 나오는 방식
- 푸시 (Push): 함수가 호출되면 해당 함수의 실행 정보(실행 문맥/컨텍스트)를 스택의 맨 윗부분에 쌓아 올립니다. 엔진은 항상 맨 위에 쌓인 최신 함수를 실행합니다.
- 팝 (Pop): 실행 중인 함수가 연산을 마치고 결과를 반환하면, 스택의 맨 위에서 해당 함수 정보를 제거합니다. 제거와 동시에 바로 아래에 대기 중이던 이전 함수로 실행 흐름이 복귀합니다.

```js
// 호출 스택의 변동 흐름 확인
function first() {
    console.log("2. first 함수 시작");
    second(); // second 함수를 호출하여 스택에 추가(Push)합니다.
    console.log("4. first 함수 종료");
}

function second() {
    console.log("3. second 함수 실행 및 종료"); 
    // 종료와 동시에 second가 스택에서 제거(Pop)되어 제어권이 first로 복귀합니다.
}

console.log("1. 전역 실행 시작");
first(); // first 함수를 호출하여 스택에 추가(Push)합니다.
console.log("5. 전역 실행 종료");
```

#### 클로저 (Closure)의 생성과 작동 원리
함수가 호출 스택에서 종료되어 제거(Pop)되면 해당 함수 내부에 선언된 지역 변수들도 원칙적으로 소멸합니다.  
그러나 외부 함수의 실행이 끝나 소멸하더라도, 외부 함수 내부에서 반환된 내부 함수가 외부 함수의 지역 변수를 지속적으로 참조하고 있다면 해당 변수 공간은 메모리에서 해제되지 않고 유지됩니다. 이러한 메모리 보존 현상 및 선언 환경의 조합을 `클로저(Closure)`라고 합니다.

```js
// 클로저 구현을 통한 내부 변수 은닉화
function createSecureStorage() {
    let secureValue = "보안용 내부 데이터"; // 외부에서 멤버 속성으로 직접 참조 불가능한 지역 변수

    return {
        getData: function() {
            return secureValue; // 클로저가 적용되어 외부 함수가 소멸된 뒤에도 secureValue를 추적할 수 있습니다.
        },
        setData: function(newValue) {
            secureValue = newValue; // 검증 과정을 탑재하여 내부 변수를 안전하게 업데이트할 수 있습니다.
        }
    };
}

const myStorage = createSecureStorage();

console.log("기본 값 조회:", myStorage.getData()); // 출력: 보안용 내부 데이터
myStorage.setData("수정된 보안 데이터");
console.log("수정 값 조회:", myStorage.getData()); // 출력: 수정된 보안 데이터

try {
    console.log(secureValue); // 외부에서 직접 scope 내부의 변수를 호출하려 시도하면 에러가 납니다.
} catch (e) {
    console.log("직접 접근 실패 에러:", e.message); // 출력: secureValue is not defined
}
```

### 2.7 명시적 this 바인딩 (call, apply, bind)
함수 내부의 `this` 주체를 런타임에 인위적으로 결정하고 싶을 때 사용합니다.

#### 1) call 메서드
함수를 즉시 실행하면서, 첫 번째 인수로 전달받은 객체를 해당 함수의 `this`로 강제 지정합니다. 두 번째 인수부터는 함수에 넘겨줄 데이터를 쉼표로 구분하여 개별적으로 전달합니다.
```js
// call 메서드를 활용한 즉시 호출 및 개별 인수 전달
function introduce(greeting, symbol) {
    // 여기서 this는 call을 통해 유입되는 객체를 가리킵니다.
    console.log(`${greeting}${symbol} 저는 ${this.name}입니다.`);
}

const personA = { name: "이용교" };

// 첫 번째 인자로 personA 객체를 대입하여 함수의 this를 고정합니다.
// 두 번째, 세 번째 인자는 순서대로 introduce 함수의 매개변수 자리에 대입됩니다.
introduce.call(personA, "안녕하세요", "!"); // 출력: 안녕하세요! 저는 이용교입니다.
```

#### 2) apply 메서드
`call`과 동일하게 즉시 실행하며 `this`를 고정합니다. 차이점은 함수에 넘겨줄 인수들을 개별적으로 나열하는 것이 아니라 하나의 배열 형태로 한꺼번에 전달한다는 점입니다.
```js
// apply 메서드를 활용한 즉시 호출 및 배열 인수 전달
function introduce(greetings, symbol) {
    // 여기서 this는 apply를 통해 유입되는 객체를 가리킵니다.
    console.log(`${greetings}${symbol} 저는 ${this.name}입니다.`);
}

const personB = { name: "홍길동" };

// 첫 번째 인자로 personB 객체를 대입하여 함수의 this를 고정합니다.
// 함수에 대입할 매개변수들은 대괄호([])를 이용한 배열 데이터 형식으로 전달합니다.
introduce.apply(personB, ["반갑습니다", "."]); // 출력: 반갑습니다. 저는 홍길동입니다.
```

#### 3) bind 메서드
`call`, `apply`와 다르게 함수를 즉시 실행하지 않고, 전달받은 객체가 `this`로 고정된 새로운 함수를 "복제"하여 반환합니다. 새로운 함수를 생성할 때 일부 매개변수에 할당할 인수 데이터를 미리 고정(사전 구성)해 둘 수도 있습니다.
```js
// bind 메서드를 활용한 새로운 함수 복제 및 인수 사전 고정
function introduce(greeting, symbol) {
    // 여기서 this는 bind를 통해 영구 결합될 객체를 가리킵니다.
    console.log(`${greeting}${symbol} 저는 ${this.name}입니다.`);
}

const personA = { name: "이용교" };

// this 값만 personA로 고정한 복제 함수 생성 (즉시 실행되지 않음)
const bindOnlyThis = introduce.bind(personA); 
// 복제된 새로운 함수를 실행하는 시점에 매개변수 인수들을 넘겨줍니다.
bindOnlyThis("안녕하세요", "!"); // 출력: 안녕하세요! 저는 이용교입니다.

// this 값과 첫 번째 매개변수(greeting)의 인수까지 고정하여 생성
// 두 번째 인자로 "안녕하십니까"를 제공하여 첫 번째 매개변수 자리에 영구 결합시킵니다.
const bindWithGreeting = introduce.bind(personA, "안녕하십니까");
// 복제된 함수를 호출할 때는 고정되지 않은 나머지 매개변수(symbol)의 인수만 차례대로 넣어줍니다.
bindWithGreeting("?"); // 출력: 안녕하십니까? 저는 이용교입니다.
```

## 3. 오늘의 핵심
- ⭐️ 반드시 기억할 내용: 함수 선언문과 함수 표현식의 차이, 함수는 일급 객체이므로 변수에 저장하거나 다른 함수의 인수로 전달하고 반환할 수 있다. 콜백 함수는 다른 함수에 인수로 전달되어 내부에서 실행되는 함수이다.
- 💡 참고로 알아둘 내용: 화살표 함수는 일반 함수를 간결하게 작성할 수 있지만 자체 `prototype`, `arguments`, `this`를 가지지 않으며 생성자 함수로 사용할 수 없다.
- ⚠️ 헷갈리기 쉬운 주의점: 함수 선언문은 호이스팅되어 선언 전에 호출할 수 있지만 `const`에 할당한 함수 표현식은 할당 전에 호출할 수 없다. 클로저는 내부 함수가 바깥 함수 자체를 기억하는 것이 아니라 필요한 바깥 스코프의 변수를 계속 참조하는 것이다.
- 📝 한 문장 요약: JavaScript의 함수는 값처럼 전달할 수 있는 일급 객체이며, 실행 과정과 스코프를 이해하면 콜백, 클로저와 this 바인딩의 동작을 이해할 수 있다.
