## 2. 개념과 용어 정리

### 1. 객체 리터럴(Object Literal)
- 객체는 이름(키)과 값(값)을 쌍으로 묶은 데이터를 여러 개 모은 복합 데이터 타입

#### (1) 프로퍼티 읽기와 조작
- 프로퍼티(Property) : 객체의 데이터 (이름 + 값)
- 프로퍼티 읽기와 조작 (추가, 수정, 삭제)
  - 마침표(.) 연산자 : `객체명.프로퍼티이름` 형식으로 프로퍼티 값에 접근
  - 대괄호([]) 연산자 : `객체명['프로퍼티이름']` 형식, 문자열로 변수에 담긴 프로퍼티에 접근 가능
  - 없는 프로퍼티 접근 : 객체에 정의되지 않은 프로퍼티를 읽으려고 시도하면 `undefined`를 반환

```javascript
const card = { suit: "하트", rank: "A" };

// 프로퍼티 값 읽기
console.log(card.suit);     // 마침표 연산자 사용 -> 출력: 하트
console.log(card['rank']);  // 대괄호 연산자 사용 -> 출력: A
console.log(card.color);    // 없는 프로퍼티 접근 -> 출력: undefined

// 프로퍼티 추가 및 수정
card.value = 14;            // 존재하지 않는 프로퍼티 키에 값을 대입하면 새로 추가됩니다.
card.suit = "스페이드";      // 존재하는 프로퍼티 키에 값을 새로 대입하면 값이 수정됩니다.
console.log(card);          // 출력: { suit: "스페이드", rank: "A", value: 14 }

// 프로퍼티 삭제
delete card.rank;           // delete 연산자를 사용하여 특정 프로퍼티를 삭제합니다.
console.log(card);          // 출력: { suit: "스페이드", value: 14 }
```

- in 연산자 (key만 찾음) : 특정 프로퍼티가 객체에 존재하는지 여부를 반환 (값은 `true`, `false`)

#### (2) 메서드(Method)와 this
- 메서드(Method) : 프로퍼티에 저장된 값의 타입이 함수(Function)인 경우를 의미
- this 키워드 : 메서드 내에서 `this`는 메서드를 호출한 객체 자신을 가리킴

#### (3) 객체는 참조타입(Reference Type)
- 참조의 정의 : 객체는 메모리 영역을 직접 점유, 객체 타입의 값을 변수나 상수에 대입하면 실제 값이 아닌 메모리상의 위치 정보(참조)가 저장됨.
- 참조 공유 : 하나의 객체를 가리키는 참조를 다른 변수에 할당하면, 동일한 주소를 공유하게 되므로, 한쪽 변수로 객체를 변경하면 다른 쪽 변수로 접근했을 때도 변경 사항이 그대로 반영됨.

```javascript
const obj1 = { value: 10 };
const obj2 = obj1; // obj2는 obj1과 동일한 객체를 참조합니다.

console.log(obj1.value); // 출력: 10
console.log(obj2.value); // 출력: 10

obj2.value = 20; // obj2를 통해 객체의 값을 변경합니다.

console.log(obj1.value); // 출력: 20 (obj1의 값도 변경됩니다)
console.log(obj2.value); // 출력: 20
```

### 2. 배열(Array)과 데이터 관리

- 배열은 순서가 있는 여러 개의 데이터를 연속적으로 나열, 관리하는 객체 타입의 자료구조

#### (1) 배열 리터럴 생성과 length 프로퍼티
- 배열 요소(Element) : 배열 내부에 들어있는 각각의 데이터를 의미
  - 인덱스(Index) : 배열 요소에 부여된 번호로, 0부터 시작하는 정수
  - length : 배열의 최대 인덱스 값에 1을 더한 값을 나타내며, 배열의 길이를 정의

#### (2) Array 생성자와 배열의 본질
- Array 생성자 : `new Array()` 형식으로 배열을 동적 생성할 수 있다. 인수가 하나이고 양의 정수인 경우, 그 수만큼 길이를 가진 빈 배열을 만듦
- 배열의 실체 : 자바스크립트의 배열은 연속된 메모리 공간을 차지하는 물리 배열이 아니라, Array 객체임. 인덱스 번호를 문자열 키로 변환하여 프로퍼티로 활용하는 가상 배열 구조입니다.

#### (3) 배열 요소의 추가와 삭제
- 요소 추가 : 배열에 지정되지 않은 인덱스 번호에 값을 직접 대입하거나, `push` 메서드를 사용하여 끝에 추가
- delete 연산자 : 특정 인덱스의 요소를 제거하지만, 배열의 `length`는 감소하지 않고 해당 요소의 값만 `undefined`가 됨

#### (4) 배열 주요 메서드 정리

##### 1. 원본 배열을 직접 변경
- `push(값)` : 맨 뒤에 추가
- `pop()` : 맨 뒤 요소 제거
- `unshift(값)` : 맨 앞에 추가
- `shift()` : 맨 앞 요소 제거
- `splice(위치, 개수, 추가값)` : 원하는 위치의 요소 삭제/추가
- `reverse()` : 배열 순서를 반대로 변경

##### 2. 원본은 유지하고 새로운 결과 반환
- `slice(시작, 끝)` : 배열의 일부를 잘라 새 배열 반환
- `concat(배열)` : 배열들을 합쳐 새 배열 반환
- `join(구분자)` : 배열 요소를 문자열로 연결

##### 3. 배열을 순회하며 작업
- `forEach()` : 요소를 하나씩 돌면서 작업 수행
- `map()` : 각 요소를 가공하여 새 배열 생성
- `filter()` : 조건에 맞는 요소만 골라 새 배열 생성
- `some()` : 조건을 만족하는 요소가 하나라도 있는지 확인
- `every()` : 모든 요소가 조건을 만족하는지 확인
- `reduce()` : 모든 요소를 계산하여 하나의 결과로 누적

##### 우선 기억할 것
- 추가/삭제 : `push`, `pop`, `splice`
- 반복 : `forEach`
- 변환 : `map`
- 조건으로 찾기 : `filter`
- 일부 잘라내기 : `slice`

⚠️ `slice`와 `splice`는 이름이 비슷하므로 주의
- `slice` → 원본 유지, 잘라서 복사
- `splice` → 원본 배열을 직접 수정

#### (5) 다차원 배열과 유사 배열 객체
- 다차원 배열 : 배열 요소 내에 또 다른 배열을 포함시켜 격자형 데이터 구조를 구축
- 유사 배열 객체(Array-like Object) : 배열은 아니지만 0 이상의 정수 프로퍼티 이름과 `length` 프로퍼티를 가진 객체. `Array.prototype`의 메서드를 간접 호출하여 제어할 수 있음

#### (6) Map과 Set 객체
- Map : 키와 값의 쌍을 저장하는 자료구조. 키의 타입에 제한이 없고 크기를 `size` 프로퍼티로 빠르게 구함
- Set : 중복을 허용하지 않는 고유한 값들의 집합을 관리하기 위한 객체

### 3. 구조 분해 할당과 전개 연산자

#### (1) 배열 구조 분해 할당(Array Destructuring)
배열 구조 분해 할당은 배열의 요소를 순서대로 분해하여 개별 변수에 할당하는 문법. 배열의 인덱스 위치를 기준으로 순차적인 대입이 이루어짐
- 기본 할당과 요소 건너뛰기 : 배열 내부에 있는 값을 순서대로 변수에 대입하며, 쉼표를 비워두는 방식으로 원하지 않는 인덱스의 요소를 건너뛸 수 있음
- 기본값 설정과 나머지 요소 수집(...) : 대입할 배열의 길이보다 할당받을 변수의 개수가 많을 때 발생할 수 있는 `undefined`를 방지하기 위해 기본값을 지정할 수 있음. 또한 첫 몇 개의 요소를 제외한 나머지 요소를 다시 배열로 모으고 싶을 때는 전개 연산자 패턴(`...변수명`)을 마지막에 배치

#### (2) 객체 구조 분해 할당(Object Destructuring)
객체 구조 분해 할당은 객체의 프로퍼티 키를 기준으로 데이터를 분해하여 변수에 할당. 순서가 중요했던 배열과 달리 키(key) 이름이 일치하는 변수에 값이 연결됨
- 기본 할당과 변수 이름 변경 : 객체 프로퍼티 키와 동일한 이름으로 변수를 선언하면 값이 자동으로 매핑. 만약 객체의 키와 다른 이름의 변수를 사용하고 싶다면, 콜론(`:`)과 함께 원하는 변수 이름을 지정 (`기존키: 새변수명`)
- 중첩 객체 분해와 기본값 지정 : 객체 내부의 또 다른 객체 구조를 추적하여 하위 프로퍼티를 직접 추출할 수 있으며, 객체에 해당 키가 존재하지 않을 때 적용할 기본값 설정도 가능

#### (3) 계산된 키를 활용한 구조 분해 할당(Computed Property Destructuring)
객체의 키 이름을 코드가 실행되는 시점(런타임)에 동적으로 결정해야 할 때가 있습니다. 이때 대괄호 안에 변수나 표현식을 넣는 계산된 프로퍼티 이름 규칙을 구조 분해 할당 구문에도 그대로 적용할 수 있습니다.
- 계산된 접근 구문 (`{[키값 변수]: 받을 변수명}`) : 동적으로 변하는 변수의 값을 객체의 프로퍼티 키로 해석하게 한 뒤 그 키에 해당하는 값을 우측에 지정한 새로운 변수에 할당

#### (4) 전개 연산자(Spread Operator, ...)
전개 연산자 `...`는 배열이나 객체처럼 반복 가능하거나 구조화된 데이터 묶음을 개별 요소로 펼쳐주는 역할. 대입 연산자 왼쪽에 쓰이는 구조 분해 할당과 달리, 값을 선언하거나 전달하는 곳에 쓰임
- 배열에서 활용 (복사 및 병합) : 기존 배열의 값을 펼쳐서 새로운 배열을 생성하므로, 원본 배열의 주소값을 공유하지 않는 얕은 복사(Shallow Copy)가 가능하며 두 배열을 결합할 때도 유용함
- 객체에서의 활용 (복사 및 프로퍼티 덮어쓰기) : 객체를 복사하면서 특정 프로퍼티를 추가하거나, 기존 프로퍼티를 덮어써서 수정된 새로운 객체를 리턴하고자 할 때 자주 사용. 뒤쪽에 선언된 프로퍼티 키가 항상 앞쪽 프로퍼티를 덮어씀

### 4. 내장 생성자와 내장 객체

자바스크립트 엔진은 실행되는 즉시 사용할 수 있는 공통 내장 생성자와 유틸리티 객체를 제공함. 이를 분류 규칙에 따라 파악하고 있으면 복잡한 저수준 기능의 직접 구현 없이 빠른 개발이 가능함

#### (1) 자바스크립트 객체의 3대 분류
자바스크립트가 제공하거나 지원하는 객체는 출처에 따라 다음과 같이 세 종류로 나뉩니다.
- 네이티브 객체 (표준 내장 객체) : ECMAScript 명세 정의 / `Object`, `Array`, `Math` 등
- 호스트 객체 : 실행 환경(브라우저, Node.js)이 제공 / `window`, `document`, `XMLHttpRequest`, Node.js의 `process`, `Buffer` 등
- 사용자 객체 : 프로그래머가 필요에 따라 생성

#### (2) Function 생성자 사용 지양의 이유
`new Function("인수", "본문")` 형식으로 동적 함수를 선언 가능
- 단점 : `Function` 생성자를 통해 만들어진 함수는 호출 시 전역 스코프에서 바인딩되므로 지역 변수를 참조할 수 없으며, 입력받은 임의의 문자열을 실행할 수 있어 보안(XSS 등)적인 문제가 발생할 우려가 있어 특수한 경우를 제외하고는 사용하지 않는 것이 권장됩니다.

#### (3) 전역 객체(Global Object)와 프로퍼티
전역 객체는 자바스크립트 프로그램의 어느 위치에서나 사용할 수 있는 최상위 객체. 엔진이 시작될 때 실행 환경에 맞춰 자동으로 생성되며, 전역 변수와 전역 함수를 프로퍼티로 가짐. 실행 환경에 따라 전역 객체를 가리키는 식별자가 다름
- 웹 브라우저 환경 (`window`) : 브라우저 창을 제어하는 역할. DOM 객체나 브라우저 제어 기능을 프로퍼티로 포함
- Node.js 환경 (`global`) : 서버 사이드에서 실행하기 위한 환경. 시스템 정보나 프로세스를 제어하는 `process`, `Buffer` 등을 프로퍼티로 포함
- 통합 전역 객체 (`globalThis`) : ES2020(ES11)에 표준으로 추가되어 환경에 상관없이 전역 객체를 가리키는 보편적인 속성

### 5. 원시 타입과 래퍼 객체(Primitive Wrapper Objects)

원시 래퍼 객체는 문자열, 숫자, 불리언 등의 원시 타입 데이터가 객체처럼 메서드를 호출할 수 있도록 자바스크립트 엔진이 일시적으로 생성하는 내장 객체

#### (1) 자동 박싱(Auto-Boxing)과 언박싱(Unboxing)
기본형인 `string`은 메모리에 단순 문자 데이터만 저장되는 원시값(Primitive Value)임. 원시값은 객체가 아니므로 스스로 메서드를 가질 수 없음. 그러나 마침표(`.`) 연산자를 사용해 문자열을 가공할 때 엔진이 순간적으로 래퍼 객체로 감싸서(Auto-Boxing) 메서드를 실행하고 다시 원시값으로 되돌림(Unboxing).

#### (2) new 연산자를 이용한 래퍼 객체 직접 생성 시의 문제점
`new String()`, `new Number()`, `new Boolean()` 등 생성자 함수를 사용하여 원시값을 인위적으로 포장할 수 있음. 그러나 이는 실제 원시 타입이 아닌 객체 타입을 생성하므로, 타입 비교나 조건식 평가 단계에서 의도치 않은 논리적 오류를 야기할 수 있어 사용을 지양함.

## 3. 오늘의 핵심
- ⭐ 반드시 기억할 내용: 객체는 `key:value` 형태의 프로퍼티로 데이터를 관리하고, 배열은 여러 데이터를 인덱스 순서로 관리한다. 배열 안에 객체를 넣는 구조도 자주 사용된다.
- 💡 참고로 알아둘 내용: 구조 분해 할당과 전개 연산자(`...`)를 사용하면 배열이나 객체의 데이터를 분리하거나 펼쳐서 간편하게 사용할 수 있다.
- ⚠️ 헷갈리기 쉬운 주의점: 배열에서 `delete`를 사용하면 요소가 당겨져 삭제되는 것이 아니라 해당 위치가 빈칸으로 남는다. 실제 요소 삭제에는 `splice()` 등을 사용하는 것이 적절하다.
- 한 문장 요약: 객체와 배열을 이용해 여러 데이터를 구조적으로 관리하고, 필요한 데이터를 읽고 수정하거나 배열 메서드를 통해 가공하는 방법을 학습했다.

## 4. 느낀 점과 다음 학습
- 잘 이해한 부분: 객체의 프로퍼티와 배열 요소의 차이, 프로퍼티 추가·수정·삭제, 배열의 기본적인 데이터 관리 방식
- 아직 어려운 부분: `map`, `filter`, `reduce` 등 배열 반복 메서드는 종류가 많아 실제 코드에서 어떤 것을 선택해야 하는지 아직 익숙하지 않다.
- 다음에 복습할 내용: `push`, `splice`, `forEach`, `map`, `filter` 등 자주 사용하는 배열 메서드와 객체·배열을 함께 사용하는 구조
- 오늘의 느낀 점: 처음 보는 내용이 많아 복잡했지만, 객체는 `key:value`, 배열은 순서와 인덱스로 데이터를 관리한다는 기준을 잡으니 조금씩 구조가 보이기 시작했다. 메서드나 내장 객체를 전부 외우기보다는 필요한 기능을 찾아서 사용할 수 있도록 기본 구조를 이해하는 것이 중요하다고 느꼈다.
