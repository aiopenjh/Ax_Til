## 2. 개념과 용어 정리
 - 객체 리터럴(Object Literal) :객체는 이름(키)과 값(값)을 쌍으로 묶은 데이터를 여러개 모은 복합 데이터 타입
   - 프로퍼티(Property) : 객체의 데이터 (이름+값)
   - 프로퍼티 읽기와 조작(추가, 수정, 삭제)
    - 마침표(.)연산자 : 객체명.프로퍼티이름 형식으로 프로퍼티값에 접근
    - 대괄호([])연산자 : 객체명['프로퍼티이름'] 형식, 문자열로 변수에 담긴 프로퍼티에 접근가능
    - 없는 프로퍼티 접근 : 객체에 정의되지 않은 프로퍼티를 읽고 읽으려고 시도하면 undefined를 반환
```javascript
const card = { suit: "하트", rank: "A" };

// 프로퍼티 값 읽기
console.log(card.suit);     // 마침표 연산자 사용 -> 출력: 하트
console.log(card['rank']);  // 대괄호 연산자 사용 -> 출력: A
console.log(card.color);    // 없는 프로퍼티 접근 -> 출력: undefined

// 프로퍼티 추가 및 수정
card.value = 14;            // 존재하지 않는 프로퍼티 키에 값을 대입하면 새로 추가됩니다.
card.suit = "스페이드";      // 존재하는 프로퍼티 키에 값을 새로 대입하면 값이 수정됩니다.
console.log(card);          // 출력: { suit: "스페이드", rank: "A", value: 14 }

// 프로퍼티 삭제
delete card.rank;           // delete 연산자를 사용하여 특정 프로퍼티를 삭제합니다.
console.log(card);          // 출력: { suit: "스페이드", value: 14 }
```
- in 연산자(key만 찾음)-> 특정 프로퍼티가 객체에 존재하는지 여부를 반환 값은 true, false

### 메서드(Method)와 this
 - 메서드(Method) : 프로퍼티에 저장된 값의 타입이 함수(Function)인 경우르 의미
 - this 키워드 : 메서드 내에서 this는 메서드를 호출한 객체 자신을 가리킴

### 객체는 참조타입(Reference Type)
 - 참조의 정의 : 객체는 메모리 영역을 직접 점유, 객체 타입의 값을 변수나 상수에 대입하면 실제 값이 아닌 메모리 상의 위치 정보(참조)가 저장됨.
 - 참조 공유 : 하나의 객체를 가리키는 참조를 다른 변수에 할당하면, 동일한 주소를 공유하게 되므로, 한쪽 변수로 객체 변경하면 다른쪽 변수로 접근했을 때도 변경 사항이 그대로 반영됨.
 
```javascript
const obj1 = { value: 10 };
const obj2 = obj1; // obj2는 obj1과 동일한 객체를 참조합니다.

console.log(obj1.value); // 출력: 10
console.log(obj2.value); // 출력: 10

obj2.value = 20; // obj2를 통해 객체의 값을 변경합니다.

console.log(obj1.value); // 출력: 20 (obj1의 값도 변경됩니다)
console.log(obj2.value); // 출력: 20
```

## 배열(Array)과 데이터 관리
 - 배열은 순서가 있는 여러개의 데이터를 연속적으로 나열,관리 하는 객체 타입의 자료구조
### 배열 리터럴 생성과 length 프프로퍼티
 - 배열 요소(Elment) : 배열 내부에 들어있는 각각의 데이터를 의미
   - 인덱스(Index) : 배열 요소에 부여된 번호로, 0부터 시작하는 정수
   - length : 배열의 최대 인덱스 값에 1을 더한값을 나타내며, 배열의 길이를 정의

### Array 생성자와 배열의 본질
 - Array 생성자 : new Array()형식으로 배열을 동적 생성할 수 있다. 인수가 하나고 양의 정수인 경우, 그수만큼 길이를 가진 빈배열을 만듬
 - 배열의 실체 : 자바스키립트의 배열은 연속된 메모리 공간을 차지하는 물리 배열이아니라, Array객체임, 인덱스 번호를 문자열 키로 변환하여 프로퍼티로 활용하는 가상 배열 구조입니다.

### 배열 요소의 추가와 삭제
  - 요소추가 : 배열에 지정되지 않은 인덱스 번호에 값을 직접 대입하거나, push메서드를 사용하여 끝에 추가
  - delete연산자 : 특정 인덱스의 요소를 제거하지만, 배열의 length는 감소하지않고 해당 요소의 값만 undefined가 됨

### 배열 주요 메서드 정리

#### 1. 원본 배열을 직접 변경
- `push(값)` : 맨 뒤에 추가
- `pop()` : 맨 뒤 요소 제거
- `unshift(값)` : 맨 앞에 추가
- `shift()` : 맨 앞 요소 제거
- `splice(위치, 개수, 추가값)` : 원하는 위치의 요소 삭제/추가
- `reverse()` : 배열 순서를 반대로 변경

#### 2. 원본은 유지하고 새로운 결과 반환
- `slice(시작, 끝)` : 배열의 일부를 잘라 새 배열 반환
- `concat(배열)` : 배열들을 합쳐 새 배열 반환
- `join(구분자)` : 배열 요소를 문자열로 연결

#### 3. 배열을 순회하며 작업 ⭐
- `forEach()` : 요소를 하나씩 돌면서 작업 수행
- `map()` : 각 요소를 가공하여 새 배열 생성
- `filter()` : 조건에 맞는 요소만 골라 새 배열 생성
- `some()` : 조건을 만족하는 요소가 하나라도 있는지 확인
- `every()` : 모든 요소가 조건을 만족하는지 확인
- `reduce()` : 모든 요소를 계산하여 하나의 결과로 누적

### 우선 기억할 것
- 추가/삭제 : `push`, `pop`, `splice`
- 반복 : `forEach`
- 변환 : `map`
- 조건으로 찾기 : `filter`
- 일부 잘라내기 : `slice`

⚠️ `slice`와 `splice`는 이름이 비슷하므로 주의
- `slice` → 원본 유지, 잘라서 복사
- `splice` → 원본 배열을 직접 수정
