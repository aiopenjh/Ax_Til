## 2. 개념과 용어 정리

### 기본 문법과 출력, 변수 선언
- **주석** : `//` (단일 주석), `/* */` (여러 행 주석)
- `console.log("안녕")` : 파이썬의 `print("안녕")`과 같다.
- `var` : 3가지의 치명적 오류가 있다 (호이스팅 / 선언 키워드 생략 허용 / 함수 레벨 스코프 등). 이러한 이유로 `var`는 사용하지 않는다. 이걸 대체하기 위해 `let`과 `const`가 나왔다.

#### 현대 JavaScript의 해결책 : let과 const (ES6+)
- **블록 레벨 스코프(Block-level Scope)** : 변수가 자신이 선언된 `{}` 내부에서만 유효하며, 블록을 벗어나면 접근할 수 없다.
- **호이스팅 사전 차단** : `let`과 `const`도 호이스팅은 발생하지만, 선언 전에 접근하면 `ReferenceError`가 발생하므로 `var`처럼 선언 전에 사용하는 것을 방지할 수 있다.
- **let (재할당이 필요한 변수)** : 처음 값을 지정한 이후에도 다른 값을 다시 할당할 수 있다. 실행 중 값이 계속 변경되어야 하는 변수에 사용한다.
- **const (재할당이 필요 없는 변수)** : 처음 값을 할당한 이후 다른 값을 다시 할당할 수 없다. 따라서 기본적으로 `const`를 우선 사용하고, 값의 재할당이 필요한 경우에만 `let`을 사용하는 것이 일반적이다.

> 💡 **정리** : 기본은 `const` → 값의 재할당이 필요하면 `let` → `var`는 기존 코드를 읽을 수 있을 정도로만 알아둔다.

### 자바스크립트의 주요 데이터 타입

```javascript
typeof 42          // "number"
typeof "hello"     // "string"
typeof true        // "boolean"
```

- `null` : 개발자가 의도적으로 "값 없음"을 넣음
- `undefined` : 아직 값이 할당되지 않음

### 문자열의 확장 : 문자열 결합과 템플릿 리터럴 (ES6+)
- 자바스크립트에서 텍스트를 합치거나 표현하는 방식은 크게 2가지, 고전적인 더하기(`+`) 방식과 ES6 표준인 템플릿 리터럴(Template Literal) 방식
- **더하기(`+`) 방식 연결** : 문자열에 더하기를 사용하여 문자열을 양옆으로 붙이는 결합. 여러 줄을 사용하기에 불편함이 있고, 가독성이 떨어짐 / 중간중간 따옴표와 더하기가 뒤엉켜 오타와 헷갈리기 쉽다.
- **템플릿 리터럴(Template Literal)** : 백틱(`` ` ``)으로 감싼 문자열 내부에 `${변수명}`을 사용하여 표현. 표현식 사용 가능, 줄바꿈 자연스럽게 가능

### 조건문의 숨은 규칙 : Falsy(거짓 같은 값)와 Truthy(참 같은 값)
- 자바스크립트는 참/거짓을 식별하는 명확한 불리언 타입이 아니더라도, 제어문(조건문) 내에서 참 또는 거짓의 값을 인식해 동작하는 고유한 성질이 있습니다. 이를 **Truthy / Falsy**라고 합니다.

#### Falsy (값으로 false를 자동 인식하는 6가지)
1. `false`
2. `0`
3. `""` (빈 문자열)
4. `null`
5. `undefined`
6. `NaN`

#### Truthy / Falsy 와 논리 NOT (!)
- **Truthy** : 조건문에서 `true`로 취급되는 값
- **Falsy** : 조건문에서 `false`로 취급되는 값 (`false`, `0`, `""`, `null`, `undefined`, `NaN`)
- `!` (NOT) : 조건의 참/거짓을 반대로 뒤집는 논리 연산자
  - `true` → `false`
  - `false` → `true`
  - 원래 값을 변경하는 것이 아니라 조건을 반대로 판단한다.

```javascript
let name = "";

if (name) {
    console.log("이름이 있습니다.");
}
// name은 빈 문자열(Falsy)이므로 실행되지 않음

if (!name) {
    console.log("이름이 없습니다.");
}
// name → false 취급
// !name → !false → true가 되어 실행
```

#### 비교 및 논리 연산자

| 연산자 | 종류 | 설명 |
| :--- | :--- | :--- |
| `===` | 일치 연산자 | 값 + 타입까지 같은가? |
| `!==` | 불일치 연산자 | 값 또는 타입이 다른가? |
| `&&` | 논리 AND | 둘 다 참이어야 `true` |
| `\|\|` | 논리 OR | 하나만 참이어도 `true` |
| `!` | 논리 NOT | 참/거짓 뒤집기 |

### switch-case 선택문

- **switch-case** : 하나의 변수나 표현식의 값을 여러 `case`와 비교하여, 일치하는 값에 해당하는 코드를 실행하는 조건문이다.
- **case** : `switch`가 받은 값과 비교하는 역할을 하며, 값이 일치하면 해당 case부터 코드가 실행된다.
- **break** : 해당 case의 실행이 끝난 뒤 switch문을 빠져나가는 역할을 한다. break가 없으면 다음 case의 코드까지 이어서 실행될 수 있다.
- **default** : 어떤 case와도 값이 일치하지 않을 때 마지막으로 실행되는 기본 처리 영역이다.

#### 실행 흐름
- `switch` → 값 확인 → 일치하는 `case` 찾기 → 코드 실행 → `break`로 탈출
- 일치하는 `case`가 없을 경우 → `default` 실행

### 반복문 (for, while, do-while)

#### 1. for문
- 정해진 횟수만큼 반복할 때 사용
- **for문을 구성하는 3대 요소** : 
  1. **초기화식** : 시작될 때 한 번만 실행. 반복 횟수 제어용 변수를 선언하고 값을 할당 (for문 안에서만 사용 가능)
  2. **조건식** : 매 반복 직전에 평가하여 `true`면 실행, `false`면 반복 종료
  3. **증감식** : 반복마다 변수값을 증가 또는 감소

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

#### 2. 중첩 for문 (Nested Loop) : 반복문 속에 반복문
- 구구단 전체 출력, 별 찍기 등 여러 줄과 열을 출력할 때 사용
- 바깥 for문(행)이 한 번 돌 때, 안쪽 for문(열)이 모두 돈다.

```javascript
for (let i = 2; i <= 9; i++) {
    console.log(`${i}단`);
    for (let j = 1; j <= 9; j++) {
        console.log(`${i} x ${j} = ${i * j}`);
    }
}
```

#### 3. while문 : 조건이 참인 동안 계속 반복하기
- 조건식의 평가 결과가 참인 동안 `{}` 내부의 코드를 계속 반복 실행
- `for`문은 보통 반복 횟수가 정해져 있으나, `while`문은 조건이 만족되는 동안에는 끝없이 실행
- `while` 뒤의 조건식 뒤에 세미콜론(`;`)을 찍지 않도록 주의
- `while`문은 뒤에 `false`가 나오지 않는 한 무한 루프를 돎, 무한 루프 방지 필수!!

```javascript
let count = 0; // 5가 넘으면 종료
while (count < 5) { // 조건
    console.log(count); // 실행
    count++; // 5를 넘어가도록 설정
}
```

#### 4. do-while문 : 일단 한 번 실행하고 조건 비교하기
- `while`문은 시작할 때 조건식부터 검사하지만, `do-while`문은 참/거짓을 떠나 무조건 1회 코드를 실행한 뒤에 검사
- `do-while`문 또한 무한 루프에 빠질 수 있어 증감식 필수!!

```javascript
console.log("--- do-while 루프 시작 ---");

let hasTicket = false; // 티켓이 없는 상태(false)

// 조건이 false이지만, do 블록은 조건 검사 전에 무조건 1회 실행됩니다.
do {
    console.log("놀이기구에 일단 탑승하여 재미있게 즐깁니다!");
} while (hasTicket === true); // 이후 조건 검사 시 false이므로 다음 루프를 돌지 않고 바로 빠져나갑니다.

console.log("--- do-while 루프 종료 ---"); // 만약! hasTicket이 true면 무한 루프다!!
```

### 반복문의 흐름 제어 : break와 continue
- `break` : 반복문을 즉시 중단하고 빠져나감
- `continue` : 현재 반복을 건너뛰고 다음 반복을 실행

```javascript
// continue : 짝수만 출력
for (let i = 0; i < 10; i++) {
    if (i % 2 !== 0) continue;
    console.log(i);
}

// break : 5까지만 출력
for (let i = 0; i < 10; i++) {
    if (i > 5) break;
    console.log(i);
}
```

### 예외 처리 (try - catch - finally)
- **예외 처리 (Exception Handling)** : 코드 실행 중 예상 못한 에러가 발생하면 강제 종료되지만, 예외 처리는 강제 종료되지 않고 미리 준비한 대안을 코드로 실행해 안정적인 동작을 유지하게 돕는 제어 처리입니다.
- **try 블록 (감시 구역)** : 에러가 발생할 가능성이 있는 코드를 넣어두는 감시 지역, 에러가 발생하면 즉시 `catch` 블록으로 이동해 에러를 처리
- **catch 블록 (대응 구역)** : `try` 블록에서 에러가 발생했을 때 실행될 코드
- **finally 블록 (마무리 작업, 선택 사항)** : `try` 블록에서 에러가 나든 안 나든 항상 마지막으로 무조건 실행될 코드

```javascript
try {
    // 1. 시도할 코드 (예: 존재하지 않는 변수에 접근)
    console.log(myVariable);
} catch (error) {
    // 2. 에러가 발생했을 때 실행할 코드
    console.error("에러가 발생했습니다:", error.message);
    // 사용자에게 친절한 에러 메시지 표시
} finally {
    // 3. 에러 발생 여부와 상관없이 항상 실행할 코드
    console.log("예외 처리 로직이 완료되었습니다.");
}
```

- `catch(error)`로 전달되는 에러 객체는 에러에 대한 세부 정보를 포함하고 있습니다.
  - `error.name` : 에러의 종류(type)
  - `error.message` : 에러 메시지
  - `error.stack` : 에러가 발생한 코드의 위치(stack trace)
