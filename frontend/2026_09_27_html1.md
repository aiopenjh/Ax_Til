## 2. 개념과 용어 정리

### 반응형 웹의 기초 : 미디어 쿼리 (@media)
- **미디어 쿼리 (Media Query)** : 접속한 기기의 특성(화면 타입, 가로 너비 등)을 브라우저가 감지하여, 지정된 조건에 부합할 때만 특정 CSS 스타일 규칙을 적용하는 기술.

#### 미디어 쿼리 기본 문법 구조

```css
@media 미디어타입 and (미디어특성) {
    /* 조건에 부합할 때 적용할 스타일 */ 
}
```

- `@media` : 미디어 쿼리를 사용한다는 것을 알리는 키워드
- **미디어 타입** : `all`(전체), `print`(인쇄 미리보기), `screen`(모니터, 스마트폰 등 화면), `speech`(스크린리더 소리 내어 읽어주는 장치) 등  
- **미디어 특성** : `min-width`(뷰포트 가로 폭이 지정한 크기 이상), `max-width`(뷰포트 가로 폭이 지정한 크기 이하), `orientation`(기기 화면 방향을 감지 - `portrait`: 세로, `landscape`: 가로) 등

#### 디바이스별 표준 브레이크포인트(Breakpoint) 기준

| 디바이스 크기 | 너비 | 미디어 쿼리 | 예시 |
| :--- | :--- | :--- | :--- |
| **모바일** (작은 화면) | 320px ~ 600px | `max-width: 600px` | 스마트폰에서 보는 화면 |
| **태블릿** (중간 화면) | 600px ~ 900px | `min-width: 601px and max-width: 900px` | 태블릿에서 보는 화면 |
| **데스크탑** (큰 화면) | 900px ~ 1200px | `min-width: 901px and max-width: 1200px` | 일반 컴퓨터 모니터 화면 |
| **넓은 데스크탑** | 1200px ~ 1500px | `min-width: 1201px and max-width: 1500px` | 고화질/와이드 모니터 화면 |
| **엑스트라 넓은 데스크탑** | 1500px ~ | `min-width: 1501px` | 초고해상도/대형 와이드 모니터 화면 |

### Tailwind CSS를 활용한 반응형 스타일링

- **Tailwind CSS** : 길고 복잡한 미디어 쿼리와 스타일 코드를 작성하는 대신, HTML 태그 내 클래스 선언부에 직관적인 유틸리티 클래스를 조합하여 반응형 웹을 빠르게 설계할 수 있도록 돕는 CSS 프레임워크

#### 클래스 기본 및 접두사 구조
- **속성 - 크기 (기본 스타일)**
  - `p-4` : `p`(padding: 안쪽 여백) - `4`(단위: 16px) ⇒ 16px의 안쪽 여백을 모든 방향(상/하/좌/우)에 동일 적용
  - `w-80` : 가로 너비 80단위(320px)로 설정
- **상태 접두사**
  - `hover:bg-blue-600` : 마우스를 올렸을 때 배경색을 조금 더 어두운 파란색으로 변경
- **해상도 접두사**
  - `md:grid-cols-2` : 화면 너비가 태블릿 크기 이상일 때 그리드를 2열로 배치

#### Tailwind CSS 반응형 유틸리티 클래스 접두어 규칙

| 접두어 | 적용 대상 (Breakpoints) | 설명 |
| :--- | :--- | :--- |
| **없음** (기본값) | 모든 기기 (Mobile-First) | 모바일 화면 기준 기본 스타일 |
| `sm:` | 640px 이상 | 작은 화면 (Small screens) |
| `md:` | 768px 이상 | 중간 화면 (Medium screens) |
| `lg:` | 1024px 이상 | 큰 화면 (Large screens) |
| `xl:` | 1280px 이상 | 매우 큰 화면 (Extra-large screens) |
| `2xl:` | 1536px 이상 | 초대형 화면 (Super extra-large screens) |

### Flexbox 및 Grid 레이아웃 설계
- Flexbox(`flex`)와 Grid(`grid`) 속성을 활용하여 웹페이지 레이아웃 구조화하는 방법

#### Tailwind CSS - Flex / Grid 핵심 속성 비교

| Tailwind 클래스 | 기존 CSS 비교 | 의미 |
| :--- | :--- | :--- |
| `flex` | `display: flex` | Flex 사용 |
| `flex-row` | `flex-direction: row` | 가로 배치 |
| `flex-col` | `flex-direction: column` | 세로 배치 |
| `items-center` | `align-items: center` | 교차축 중앙 정렬 |
| `justify-between` | `justify-content: space-between` | 주축 양끝 정렬 |
| `grid` | `display: grid` | Grid 사용 |
| `grid-cols-3` | `repeat(3, 1fr)` | 3열 배치 |
| `col-span-2` | `grid-column: span 2` | 가로 2칸 차지 |
| `gap-4` | `gap: 16px` | 요소 사이 간격 |
