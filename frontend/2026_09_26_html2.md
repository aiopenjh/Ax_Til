## 2. 개념과 용어 정리

### 플렉스박스(1차원 정렬)

- 플렉스 박스는 요소를 가로 또는 세로 단일방향(1차원)으로 유연하게 배치하는 레이아웃 시스템
- flex-direction(정렬방향 설정): 자식 요소를 가로, 세로 방향으로 쌓을지 정렬의 기준이 되는 축 설정

flex-direction(정렬방향 설정)

| 속성 | 설명 |
|---|---|
| row | 가로(행) 방향 좌→우 |
| row-reverse | 역순 가로(행) 방향 우→좌 |
| column | 세로(열) 방향 상→하 |
| column-reverse | 역순 세로(열) 방향 하→상 |

### justify-content & align-items (정렬 속성 제어)

justify-content(메인축 정렬)

| 속성 | 뜻 | 설명 |
|---|---|---|
| flex-start | 정렬 축의 시작점 | 왼쪽부터 붙여서 배치 |
| flex-end | 정렬 축의 끝점 | 오른쪽부터 붙여서 배치 |
| center | 정렬 축의 중앙 | 중앙에 배치 |
| space-between | 정렬 축의 양 끝 | 양 끝에 붙이고 가운데 정렬 |
| space-around | 정렬 축의 주위 | 주위에 공간을 두고 정렬 |
| space-evenly | 정렬 축의 균등 | 균등하게 정렬 |

align-items(교차축 정렬)

| 속성 | 뜻 | 설명 |
|---|---|---|
| flex-start | 교차축의 시작점 | 위쪽부터 붙여서 배치 |
| flex-end | 교차축의 끝점 | 아래쪽부터 붙여서 배치 |
| center | 교차축의 중앙 | 중앙에 배치 |
| baseline | 텍스트 기준 정렬 | 텍스트를 기준으로 정렬 |
| stretch | 교차축 채우기 | 교차축 방향으로 늘려 채움 |

flex-wrap (줄바꿈 처리)

| 속성 | 뜻 |
|---|---|
| wrap | 줄바꿈 가능 (기본값) |
| nowrap | 줄바꿈 불가 (한 줄에 표시) |
| wrap-reverse | 역순 줄바꿈 |
| flex-grow | 자식요소의 성장률 |
| flex-shrink | 자식요소의 축소율 |
| flex-basis | 자식요소의 기본 크기 |
| flex | flex-grow, flex-shrink, flex-basis의 단축속성 |


## CSS Grid (2차원 격자 레이아웃)
 - Grid는 가로(행)과 세로(열)을 격자 모양으로 배치하는 바둑판 형태의 레이아웃 방식

gird-template-columns & grid-template-rows (격자 틀 설계)
 - 바둑판의 세로 칸갯수와 가로 줄의 크기를 설계하는 속성
gap : 격자와 격자 사이 간격(여백 설정)

| 속성 | 사용법 | 설명 |
|---|---|---|
| row-gap | row-gap: 20px; | 가로 줄 사이에만 20 px의 여백 |
| column-gap | column-gap: 20px; | 세로 칸 사이에만 20 px의 여백 |
| gap(축약형) | gap:20px 10px; | row-gap와 column-gap을 합친 속성 |
| gap(동일 적용) | gap: 15px; | 가로 세로 구분없이 균일 15px 한번에 선언 |

gird-column & gird-row(칸 합치기와 배치)

| 속성 | 사용법 | 설명 |
|---|---|---|
| grid-column:1 /3 ; | 1번 칸부터 3번 칸까지 합치기| 1번 세로선에서 3번 세로선까지 총 2칸 영역을 합쳐 자리잡기 |
| grid-column:span X; | grid-column: span 3; | 현재 배치된 자리에서 가로로 총 3칸 크기 차지하기 |
| grid-row: span X; | grid-row : span 2 | 현재 배치된 자리에서 세로로 총 2칸 높이 차지하기 |

place-items(격자 내부 정렬)

| 속성 | 설명 |
|---|---|
| stretch | 격자 영역에 빈틈이 없도록 상자 크기를 꽉 채움 |
| start | 격자 칸의 왼쪽 상단 모서리에서 붙여서 조그맣게 표현 |
| end | 격자 칸의 오른쪽 하단 모서리에서 붙여서 정렬 |
| center | 격자 칸의 상하좌우 정중앙에 위치하도록 모아서 배치 |
